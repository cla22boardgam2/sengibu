# 생기부 초안 도우미

초등 담임 선생님이 칩·등급·메모를 고르면, 무료 AI가 학생마다 다른 생기부 초안을 써 주는 웹앱이에요.

- 교과 평어, 창체, 행동특성 및 종합의견(행발), 통지표 종합의견
- 같은 반에서 이미 쓴 시작 표현을 피하고, 재료가 같은 학생은 미리 알려 줘요
- 문장마다 근거, 확인할 점, 보충할 관찰을 함께 보여 줘요
- 돈이 들지 않아요 (서버 없음, 무료 AI)

## 쓰는 순서

1. **설정**
   - 무료 API 키 넣기 (아래 참고, 선택)
   - 학년, 기재요령 발췌 붙여넣기
   - 평가계획: [양식 내려받기] → 학교 평가계획서 표를 칸 순서대로 옮겨 올리거나, 표를 복사해 붙여넣기
   - 창체 행사 목록 (영역 · 이름 · 짧은 설명)
   - 글자 수 상한 (바이트)
2. **학생**: 명렬표에서 이름을 복사해 붙여넣으면 S01, S02… 가명이 붙어요.
3. **입력**: 교과는 등급 버튼, 창체는 참여·역할 칩, 행발은 칩. 칩으로 안 되는 건 메모로.
4. **초안 만들기**
   - API 키가 있으면 [반 전체 생성] 한 번이면 돼요. 무료 한도에 걸리면 기다렸다가 알아서 이어 가요.
   - 키가 없으면 [프롬프트 복사] → Claude·ChatGPT·Gemini 채팅 **새 창**에 붙여넣기 → 받은 답을 [답 붙여넣기]에 넣고 [답 저장].
5. **결과 검토**: 고치고, [검토 완료]를 체크해야 [복사]가 켜져요.
6. **백업**: 가끔 백업 파일을 내려받아 두세요.

## 무료 API 키 만들기 (Google Gemini)

1. https://aistudio.google.com/apikey 에 구글 계정으로 들어가요.
2. **Create API key**를 눌러 키를 만들어요. 카드 등록은 필요 없어요.
3. 키를 복사해 앱 **설정 → AI 연결**에 붙여넣어요.

- 키는 이 브라우저에만 저장되고, 백업 파일에도 들어가지 않아요.
- 무료 등급은 보낸 내용이 구글 서비스 개선에 쓰일 수 있어요. 앱은 가명만 보내지만, 메모에 민감한 내용은 쓰지 마세요.
- 기본 모델은 `gemini-2.5-flash-lite`예요. 오류가 나면 설정의 모델 이름을 바꿔 보세요 (`gemini-2.5-flash` 등).

## 개인정보

- 학생 실명과 가명 대응표는 **이 브라우저에만** 저장돼요.
- AI에는 가명(S01…)만 보내요. 메모에 반 학생 이름을 쓰면 보내기 전에 가명으로 자동으로 바꿔요.
- 명단에 없는 이름(가족 등), 연락처, 건강·가정 정보는 메모에 쓰지 마세요.
- 공용 컴퓨터에서는 쓰지 마세요. 브라우저에 자료와 키가 남아요.

## 만든 뒤 꼭 확인할 것

1. **글자 수 기준**: 「2026학년도 학교생활기록부 기재 길라잡이(초등학교)」에서 교과·창체·행발 바이트 상한을 확인해 설정에 넣어 주세요. 행발만 1500바이트로 미리 넣어 두었어요.
   바이트 계산은 한글 3바이트, 영문·숫자·공백 1바이트, 줄바꿈 2바이트로 하고 있어요. 길라잡이 기준과 다르면 알려 주세요.
2. **실제 생성 확인**: 키를 넣고 학생 1명으로 [반 전체 생성]을 해서 초안이 잘 나오는지 봐 주세요.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들어요.
2. 이 폴더를 그 저장소의 `main` 브랜치로 올려요.
3. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔요.
4. 올릴 때마다 테스트 → 빌드 → 배포가 자동으로 돼요. 주소는 `https://<아이디>.github.io/<저장소 이름>/`예요.

## 개발

```bash
npm install
npm run dev     # 내 컴퓨터에서 실행
npm test        # 테스트
npm run build   # 배포용 빌드 (dist/)
node scripts/make-template.mjs   # 평가계획 양식 다시 만들기
```

`src/lib/sengibu-prompt.js`는 요청서 원문 그대로예요. 고치지 마세요 (테스트가 막아요).
